# 소와 로컬 디자인 비교

운영 화면은 변경하지 않고 `pnpm dev`에서만 확인하는 시안이다. 배포하지 않았다.

1. 기존 화면: http://127.0.0.1:3187/
2. 시안 화면: http://127.0.0.1:3187/?preview=editorial
3. 목록 비교: http://127.0.0.1:3187/works?preview=editorial

시안은 카드의 흰 배경·테두리·그림자를 제거하고 사진 모서리를 4px로 줄인다. 사진은 4:3, 설명은 사진 아래로 유지한다. 홈의 영문 칩 세 개와 10+ Projects 배지를 숨기고 푸터는 짙은 웜그레이로 바꾼다. 기존 사진·글·그리드·상세 배치를 유지한다.

후속 시안: 고즈넉한 명조 대신 Wanted Sans Variable을 제목·본문에 적용한다. 카드 소개는 첫 두 문장을 별도 블록으로 구분하고 문장별 최대 두 줄과 8px 간격으로 표시한다. 짧은 문장은 브라우저의 balance 줄배치를 적용한다. 임의로 본문을 다시 쓰거나 DB 원문을 바꾸지 않는다. 원래 주소와 운영 빌드는 기존 폰트·문장 표시를 유지한다.

시안 주소에서 내부 링크로 이동하면 스타일은 유지된다. 주소의 preview 옵션 없이 새로 열면 기존 화면으로 돌아온다. 관리자 화면을 바꾸는 시안은 아니다.

실행:

```bash
VITE_API_BASE_URL= VITE_API_PROXY_TARGET=https://api.teamsowa.com pnpm dev --host 127.0.0.1 --port 3187 --strictPort
```

공개 API의 기존 데이터를 조회한다. 디자인 확인용이며 운영 데이터의 입력·저장은 하지 않는다.
