### 이번 수정과 검증

- 후속 요청에 따라 작품 상세의 `공간 이야기`를 이전 UI처럼 왼쪽 개요·정보 아래로 다시 배치했다. 오른쪽은 사진 목록만 표시한다. 새 폰트와 문단 나눔은 유지하며 긴 이야기는 고정하지 않아 아래 문단까지 자연스럽게 스크롤해서 읽을 수 있다. 이전의 넓은 본문 영역 배치를 대체한다.

- 공개 제목은 Noto Serif KR Variable, 본문·메뉴·폼 및 관리자 화면은 Pretendard Variable로 적용했다. 폰트는 npm 패키지의 로컬 파일을 Vite로 묶어 같은 도메인에서 제공하며, unicode-range에 따라 필요한 글자 묶음만 내려받는다. OFL 라이선스 원문은 `public/fonts/`에 포함했다.
- `설명없음`, `설명 없음`, `설명란입니다.` 등 정확히 일치하는 빈 설명/임시 문구만 공개 카드와 상세에서 숨긴다. 실제 이야기와 DB 원문은 변경하지 않는다. 본문이 없는 작품은 `프로젝트 보기`로 안내한다.
- 이번 기준 단위 테스트 7개, lint, 운영 빌드와 전체 audit를 통과했다. 320·375·1024·1440px에서 공개 주요 화면과 관리자 로그인 화면의 가로 넘침 없음, PC 홈 설명 한 줄, 실제 한글의 새 폰트 렌더링을 확인했다. 이번에 카드 모서리·그림자, 배지나 푸터 색을 추가 개편하지는 않았다.

- AI 없이 작품 카드에는 첫 두 문장 도입을 최대 4줄로 표시하고 `공간 이야기 읽기`를 상세 페이지에 연결했다. 홈의 주요 프로젝트 카드에도 같은 상세 링크를 추가했다.
- 상세 본문은 좁은 개요 사이드바에서 넓은 읽기 영역으로 이동했다. 원문의 줄바꿈을 존중하고, 줄바꿈이 없는 글만 두 문장 단위로 나눠 표시한다. 문장과 문단 간 여백, 한국어 단어 단위 줄바꿈을 적용했다. DB의 원문과 폰트는 변경하지 않았다.
- 스토리 표시 테스트 4개를 추가해 단위 테스트는 총 6개다. 실제 긴 본문에서 원문 내용 보존 및 320·375·1024·1440px 카드/상세 가로 넘침 없음을 확인했다.

- Axios 1.20.0, React Router 7.18.4, Vite 7.3.6 및 호환되는 하위 의존성을 업데이트했다. 빌드 도구의 Browserslist와 baseline-browser-mapping 보안 패치는 `pnpm-workspace.yaml`에 고정했다.
- 배포와 같은 pnpm 10.28.0으로 전체 및 `--prod` audit를 실행했고 알려진 취약점 0건을 확인했다. 이는 서비스 전체의 보안 무결성을 보장하는 의미는 아니다.
- 잘못된 상세 주소는 API를 호출하지 않고 안내한다. 실제 404도 안내하며 서버/통신 장애는 한 번 자동 재시도 후 수동 재시도를 제공한다.
- 홈 제목은 “채워지는 바탕” 앞에서 줄을 나눈다. 설명은 데스크톱 한 줄, 모바일 자연 줄바꿈으로 유지하고 관리자 설정 원문은 변경하지 않았다.
- 단위 테스트 2개, lint, 운영 빌드와 브라우저 확인을 통과했다. 기존 500kB 초과 번들 안내와 Zod 주석 제거 경고는 빌드를 차단하지 않으며 별도 최적화 대상으로 남는다.

운영 도메인 두 개에서 주요 페이지 경로와 JS 파일의 HTTP 200 응답, 실제 백엔드 연결값, 공개 API 응답과 CORS 설정을 확인했습니다. 관리자 로그인과 문의 등록 등 데이터 변경 동작은 이번 배포에서 테스트하지 않았습니다.
